## **Overview**  
**Tarweej** is a powerful and user-friendly **photo editing application** designed for creative enthusiasts. The app provides seamless **editing tools, advanced filters, customizable brushes, and collage-making features** to help users create stunning images effortlessly.  

With multiple authentication methods, efficient **state management using Riverpod**, and secure **storage solutions**, **Tarweej** delivers a feature-rich and smooth user experience.

---

## **✨ Features**  
✅ **User Authentication**: Google, Facebook, GitHub, Phone, and Email login.  
✅ **Photo Editing**: Apply filters, adjust brightness/contrast, crop images, and use brushes.  
✅ **Collage Maker**: Create stunning collages with customizable layouts.  
✅ **State Management**: Efficiently handle app state with **Riverpod**.  
✅ **Secure Storage**: Save user preferences and edited photos using **Hive**.  
✅ **Localization Support**: Multi-language support with **Intl**.  
✅ **Dark Mode**: Toggle between light and dark themes.

## **🛠 Tech Stack & Tools**  
The **Tarweej Platform** is built using:  

- **📱 Flutter (Dart)** – Cross-platform mobile framework  
- **⚡ State Management**: Riverpod  
- **🔐 Authentication**: Firebase (Google, Facebook, GitHub, Phone, Email)  
- **💾 Storage**: Hive (Local storage)  
- **🌍 Networking**: Dio (API calls)  
- **🌎 Localization**: Intl (Multi-language support)
